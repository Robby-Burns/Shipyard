# Shipyard Documentation

This directory contains the current Shipyard foundation docs, standards, roadmap material, and expanded reference documents.

## Foundation

- `foundation/current_implementation_alignment.md` - current implementation source of truth for workflow states, gates, contracts, and runtime caveats.
- `foundation/shipyard_constitution.md` - current concise constitution.
- `foundation/shipyard_constitution_expanded.md` - normalized expanded constitution reference.
- `foundation/shipyard_architecture.md` - current concise architecture.
- `foundation/shipyard_technical_architecture_specification.md` - normalized detailed technical architecture reference.
- `foundation/shipyard_vision.md` - product and operating vision.

## Standards

- `standards/builder_guidelines.md` - Builder coding and repository guidelines.
- `standards/shipyard_role_specs.md` - normalized role specifications for Coordinator, Architect, Builder, Reviewer, QA, and Platform.
- `standards/templates/adr_template.md` - ADR template.

## Roadmap

- `roadmap/implementation_plan_v2.md` - current implementation plan.
- `roadmap/shipyard_implementation_guide.md` - normalized phased implementation guide reference.

When docs differ in level of ambition, `foundation/current_implementation_alignment.md` wins for current runtime behavior. The expanded reference documents were imported without replacing the current concise docs so they can be reviewed and merged intentionally.
